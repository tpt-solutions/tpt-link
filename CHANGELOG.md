# Changelog

All notable changes to this crate. Versions follow semver. Below 1.0.0, breaking
changes bump the minor version.

## Unreleased

### Added
- `supervisor::Supervisor`: drives a `Session` over a reopenable transport. It reconnects
  with backoff through the caller's connect function, drops the link when the peer is
  silent past the timeout, and can give up after an attempt limit. Replaces the hand-written
  loop in `examples/reconnect.rs`.
- `reliable::Channel`: acknowledged delivery over a `Transport`. Each message gets an
  id, every copy is acknowledged, and unacknowledged messages are sent again after
  `retransmit_us`. The caller receives each message once. Delivery is exactly-once,
  but not in send order. Window of at most 64. Example: `reliable_link`.
- `auth::Authenticated` (feature `auth`): seals every frame with ChaCha20-Poly1305 and
  drops frames that do not open. Each session runs an X25519 exchange authenticated
  with a pre-shared key, and data is sealed under the derived session key, so the
  session keys are fresh and earlier sessions stay secret. Control messages carry an
  HMAC-SHA256 tag. Pre-shared keys carry a one-byte id. `install_key`, `activate_key`
  and `retire_key` rotate them (up to four keys held at once). The receiver issues a
  random nonce per session, and frames verify only under it, so frames from an earlier
  session and repeats within the session are refused. A receiver that restarts sends a
  resync, so the sender recovers without a manual `renew`. Payloads are encrypted.
  Example: `authenticated_udp`. Threat model: `docs/auth-threat-model.md`.
- Keys and ephemeral secrets are wiped on drop (zeroize). Compiler copies are not.
- `envelope`: optional typed messages (Data, Heartbeat, Ack, Error) in the frame
  payload, and `Session`, which sends heartbeats on a schedule and tracks peer
  liveness. The frame format is unchanged. Example: `session`.
- `envelope::Message::Reliable { id, data }` (type byte 4) for the reliability layer.
- `Reconnector::with_max_attempts`, `gave_up`, `restart` and `with_backoff`.
  `Backoff::with_jitter` shortens waits by a seeded random share.
- `FaultyTransport`: `corrupt_version_next`, `truncate_next`, `duplicate_next`,
  `reorder_next` (with `release_held`), and seeded `random_loss`. Random loss
  repeats for the same seed, so a failing test can be replayed.
- `CanBus::max_data_len` and `CanError::MtuTooLarge`: an MTU the bus cannot carry
  is rejected by `CanTransport::new`. `SocketCanBus` reports classic CAN (8).
- `Deframer` buffer cap (`stream::MAX_BUFFER`) with an `overflowed()` counter. Byte
  scanning is linear, and CRC-32 is table-driven (1 KiB of read-only data).
- `Reassembler::replaced()` and `expired()`, and the matching totals on `CanTransport`.
- `tpt-link-cli`: `encode`, `decode` and `crc` for frames, offline. Needs the std feature.
- `examples/serial_bridge.rs` (feature `serial`): forwards frames between a serial port
  and a UDP peer, unchanged. Compiles here; not run on hardware.
- `tools/wireshark/tpt-link.lua`: Wireshark dissector for version 1 frames on UDP,
  with a CRC check. Written from `docs/wire-format.md`; not yet loaded in Wireshark.
- `docs/wire-format.md`: byte-level guide to the frame format, with a worked example.
- `testdata/vectors.json` and `tests/vectors.rs`: golden frame vectors generated by
  an independent CRC implementation (Python `zlib.crc32`).
- Examples: `loopback_hello`, `udp_echo`, `can_fragment`, `fault_injection`,
  `heartbeat_monitor`, `schema_roundtrip`.
- 21 doc examples on the public API.
- `CONTRIBUTING.md`, `SECURITY.md`, issue and pull request templates, `.gitattributes`
  and `.editorconfig`.
- Package metadata in `Cargo.toml`: repository, readme, keywords and categories.
- Randomised robustness tests (tests/robustness.rs), fixed seed.
- CI: MSRV job, no_std test job, schema drift check, caching, concurrency,
  weekly advisories, and a tag-triggered release workflow.

### Changed (breaking)
- `reconnect::Action` has a new `GiveUp` variant, returned once an outage uses up its
  attempt limit. Exhaustive matches on `Action` need an arm for it.
- `frame::FrameError::BadCrc` fields are now `carried` and `computed` (they were
  `expected` and `actual`, which read the wrong way round).
- `LinkStats` has new `bad_version` and `duplicates` counters. Frames with an unknown
  version were counted in `malformed` before.
- `Link::poll` drops a frame whose sequence number has already arrived, and counts
  it in `LinkStats::duplicates`. Duplicates used to be delivered. A late frame that
  fills an earlier gap is still delivered, if it is within the last 64 sequence numbers.
- `envelope::Message` has a new `Reliable` variant. Exhaustive matches need an arm for it.
- `UdpTransport` drops datagrams from any address other than the peer, and counts
  them in `foreign()`.

### Fixed
- The default build no longer warns about the unused `SeqWindow::arrive_strict`,
  which only the `auth` feature calls. The warning failed `clippy -D warnings`.
- `Link::poll` no longer loses payloads that arrived before a transport error. It
  returns them, and reports the error on the next call.
- `Link::poll` delivers every frame in a datagram, not only the first.
- Reordered or duplicate frames no longer count as extra loss. A large backward
  jump in sequence numbers is treated as a peer restart.
- `Reconnector::on_link_down` does nothing while the link is already down, so
  calling it on every tick no longer defeats the backoff. A zero initial backoff
  is raised to 1 us.
- `Reassembler` replaces a stale partial message when a fragment conflicts with it.
  A reused id can still mix two messages when nothing disagrees, so the link CRC
  above is what rejects the mix.
- `CanTransport` masks the sender to 3 bits and rejects an MTU with no room for data.
- `UdpTransport` no longer returns Windows `ConnectionReset` from `try_recv`.
- `VirtualBus` no longer panics on a poisoned lock.
- `cargo test --no-default-features --lib` compiles again (frame.rs tests gated on `alloc`).

## 0.2.0

### Added
- `stream::Deframer::with_timeout`, `push_at` and `next_frame_at`. A frame that
  stalls on a corrupted length field is abandoned after the timeout, so a good
  frame behind it is delivered. Discards are counted by `timeouts()`.
- `SerialTransport::stalls()`, and a 500 ms stall timeout on the serial deframer.
- `can::CanTransport`: link frames fragmented over any `CanBus` (8-byte classic or
  64-byte FD), with one reassembler per sending node. `can::VirtualBus` is an
  in-memory bus for tests.
- `can_socketcan::SocketCanBus` (feature `can-socketcan`, Linux only), tested in
  CI over a `vcan0` interface.
- `schema`: `Heartbeat`, `Ack` and `Error` from `proto/tpt_link.proto` (feature
  `proto`). Generated with micropb by `tools/gen-schema`, and no_std compatible.
- `examples/reconnect.rs`: `Reconnector` and `Heartbeat` driving a UDP link.
- `.github/workflows/ci.yml`: fmt, clippy, tests on Linux, Windows and macOS,
  doc warnings, MCU no_std builds, SocketCAN over vcan0, and cargo deny.

### Known limitations
- A UDP open only binds a local socket, so backoff does not apply to a link that
  opens but goes silent. See spec section 8.
- The serial stall timeout and SocketCAN have not been checked on hardware.
- No Windows CAN adapter. Proprietary adapter runtimes fail the licence policy.

## 0.1.0

- Frame format v1 with CRC-32, and the byte-stream deframer.
- Transports: Loopback, FaultyTransport, UdpTransport, and SerialTransport
  behind the `serial` feature.
- Link with sequence numbers and loss counts, Heartbeat, Backoff and
  Reconnector.
- Fragmentation and reassembly for small-MTU transports.
